# macOS CLI regression report

A self-contained HTML report for the **macOS/Tart** clean-VM run: every
`agentjail` CLI command exercised, each of the 15 scenarios with its own inline
**asciinema player**, a summary table that jumps to each scenario, and the
side-by-side tour (CLI ↔ live `agentjail logs`).

- **`index.html`** — open directly in a browser; fully self-contained (players,
  casts, and the tour gif are embedded as data, no external requests).
- **`casts/*.cast`** — the raw asciinema recordings, one per scenario.

## Relationship to the reportlib system

This is generated by the **mac-side** tooling and is **separate** from the
host's `reportlib.sh` / `gen-report.sh` / `report-assets/` pipeline. The
two recording systems are not yet unified:

- reportlib scenarios use the `scn_init/scn_check/scn_finish` contract + a
  `# testbed-mode:` header and emit JSON consumed by `testbed.sh record`.
- The macOS CLI scenarios (`cli-tour`, `mcp`, `skill`, `secret`, `trust`,
  `telemetry`, `ui`, `policy-mgmt`, …) use the `ok`/`bad` stdout pattern and do
  **not** emit JSON yet, so they don't appear in the reportlib `report.html`.

A shim to bridge the `ok`/`bad` scenarios into the canonical report is planned
planned as a follow-up. Until then, this report is the
showcase for the macOS scenario suite.

## Recording notes

- Each recording starts with `fastfetch` + a `time:` line for environment/context
  (neofetch is archived; fastfetch is its maintained successor).
- `/dev/tty`-gated commands (`mcp allow`/`block`, `skill ask`/`clear`,
  `policy disable`, `update`) open `/dev/tty` and block on a typed `y` under a
  recording PTY. To capture the non-interactive **refusal** path they were
  recorded in a session with **no controlling terminal** (a forked `setsid`
  wrapper), so `/dev/tty` open fails and agentjail refuses — matching CI.
- The players load via asciinema-player's inline `{data: …}` source (the cast
  text is decoded from an embedded base64 blob), not a `data:` URL — the player
  can't format-detect a bare `data:text/plain` URL.
