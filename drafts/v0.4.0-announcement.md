# v0.4.0 Release Announcement

## Tweet 1 (hook + image)

agentjail v0.4.0 is out.

The theme this release: your coding agent's sandbox stops being a static file you write once and forget. It's now a live, negotiable perimeter - scoped per session, per project, and per human approval.

Thread 1/6

---

## Tweet 2 (session-aware network proxy)

2/6 The network proxy used to run one global allowlist for every agent, everywhere.

Not anymore. Each session now registers its own allowlist through a control plane. The shield tells the proxy "this session needs api.openai.com and github.com" and gets back a scoped token.

Idle sessions get reaped automatically - no stale access lying around. (ADR 0042)

---

## Tweet 3 (per-folder policy overlays)

3/6 New: `.agentjail.yaml` in your project + `agentjail trust .`

Think direnv, but for agent policy. The shield merges project-specific rules into the session automatically once you trust a folder.

It's additive-only by design - a project can grant more access, it can never revoke a global rule. `agentjail trust list` shows exactly what's trusted, and where it came from. (ADR 0043)

---

## Tweet 4 (runtime host grants - terminal mockup)

4/6 Proxy blocks a host your agent actually needs? You don't have to restart anything.

```
$ agentjail allow api.stripe.com
  session   sess-claude-proj-alpha
  host      api.stripe.com
  scope     session only
  ? Approve this grant? [y/N] y
  ✓ granted - flowing to session now

$ agentjail allow api.stripe.com --persist
  ✓ granted - persisted to project policy

$ agentjail grants
  HOST                STATUS     SCOPE      REQUESTED BY
  api.stripe.com      approved   session    session
  evil-cdn.example    pending    --        agent
  ? Approve evil-cdn.example? [y/N] n
  ✗ denied
```

The grant flows to the running session immediately. `--persist` makes it permanent policy. And the agent is explicitly barred from approving its own grants - a human has to be in that loop, full stop. (ADR 0044)

---

## Tweet 5 (shared sandbox contract + architecture)

5/6 Under the hood:

Darwin and Linux shields now share one source of truth for paths, capabilities, and allowed hosts - no more drift where Linux allowed something macOS silently denied. Essential hosts (npm, GitHub, PyPI) are non-removable. macOS also gets keychain access for Claude Code.

Also: 12 copy-pasted audit ceremonies collapsed into a single policyctl domain service. Credential broker, hookwatch, sandbox, envaudit, policyeval - all extracted into clean internal packages. Less code, same guarantees.

macOS builds are now code-signed and notarized in CI, so no more Gatekeeper warnings on install.
